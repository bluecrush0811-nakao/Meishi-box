# 名刺ボックス

スマホで名刺を撮影して、そのままアプリ上で管理できるWebアプリです。
サーバー不要で、画像を含むデータはブラウザの `IndexedDB`(端末内)に保存されます。

## 使い方

GitHub Pages で公開している場合は、次のURLをスマホのブラウザで開きます。

https://bluecrush0811-nakao.github.io/Meishi-box/

ブラウザの共有メニューから「ホーム画面に追加」をしておくと、アプリのようにアイコンから起動できます。

1. 右下の「＋」をタップしてカメラで名刺を撮影
2. 必要なら「文字を読み取る」で氏名・会社名・電話番号などを自動入力
3. 内容を確認・修正して保存

## 主な機能

- **撮影して登録**: 表・裏の両面を保存、回転・撮り直しも可能
- **文字の自動読み取り(OCR)**: 氏名・会社名・電話・メール・住所などを自動入力
  (初回のみ OCR エンジンを CDN から読み込むため、インターネット接続が必要)
- **検索・並べ替え・タグ絞り込み**: 名前・会社・メモ・名刺上の文字で検索
- **詳細表示**: 電話・メールはタップで発信/送信、住所は地図で表示、写真は拡大表示
- **連絡先に保存**: vCard (.vcf) で書き出してスマホの連絡先に追加
- **バックアップ**: 全データを JSON で書き出し/読み込み

## データについて

- 名刺のデータは、開いた端末のブラウザ内にだけ保存されます。外部には送信されません。
- 端末やブラウザが違うとデータは別々です。移すときは「書き出し」→「読み込み」を使ってください。
- ブラウザのデータを消去すると名刺も消えるため、定期的に「書き出し」でバックアップを取ってください。
